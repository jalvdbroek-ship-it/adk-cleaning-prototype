# ADK Cleaning, conceptprototype

Visueel concept voor een nieuwe website van ADK Cleaning (glas, gevel en dak). Dit is een prototype, geen live site: beelden zijn stand-ins en het formulier verstuurt niets.

Open `index.html` via een lokale server, bijvoorbeeld `python3 -m http.server 8765`.
